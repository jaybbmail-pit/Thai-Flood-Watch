# Thai Flood Watch 🌊

เว็บแอปติดตามสถานการณ์น้ำเพื่อวางแผนรับมือน้ำท่วม แสดงข้อมูลเขื่อน/อ่างเก็บน้ำ ระดับน้ำแม่น้ำ อัตราการปล่อยน้ำ พยากรณ์อากาศ และพยากรณ์ปริมาณน้ำท่าล่วงหน้า แยกตามภาค จังหวัด และอำเภอ

เขียนด้วย Flask ไฟล์เดียว (`app.py`) และใช้ Tailwind CSS ผ่าน CDN

## ความต้องการ

- Python 3.9 ขึ้นไป
- อินเทอร์เน็ต (ดึงข้อมูลสดจากแหล่งภายนอก และโหลด Tailwind/Chart.js/Leaflet จาก CDN)

## ติดตั้งและรัน

```bash
pip install flask requests
python app.py
```

เปิดเบราว์เซอร์ที่ http://127.0.0.1:5000

หมายเหตุ: การโหลดครั้งแรกอาจช้า 15–30 วินาที เพราะต้องดึงข้อมูลสถานีวัดน้ำจำนวนมาก หลังจากนั้นใช้แคชจึงเร็วขึ้น

## วิธีใช้งาน

1. **เลือกพื้นที่** ด้านบน: ภาค → จังหวัด → อำเภอ/เขต
   - เลือกเฉพาะภาคหรือทั้งประเทศ: ดูเขื่อนและสถานีวัดน้ำ
   - เลือกจังหวัด/อำเภอ: ดูพยากรณ์อากาศและพยากรณ์น้ำท่าของพื้นที่นั้นด้วย
2. **แถบระดับความเสี่ยง**: สรุปความเสี่ยงน้ำท่วม (ต่ำ / เฝ้าระวัง / เตือนภัย / วิกฤต) พร้อมเหตุผลและข้อแนะนำ
3. **แผนที่**: สี่เหลี่ยม = เขื่อน (สีตาม % น้ำ), จุดกลม = สถานีวัดน้ำ (สีตามสถานะตลิ่ง) คลิกเพื่อดูรายละเอียด
4. **แท็บข้อมูล**
   | แท็บ | เนื้อหา |
   |---|---|
   | เขื่อน / อ่างเก็บน้ำ | ปริมาณน้ำ, % ความจุ, พื้นที่ว่างรับน้ำ, อัตราไหลเข้า–ระบาย, คาดการณ์ 7 วัน (คลิกหัวตารางเพื่อเรียง) |
   | ระดับน้ำแม่น้ำ | ระดับน้ำ, แนวโน้ม, % เทียบตลิ่ง, อัตราไหล, ค้นหา/กรองตามสถานะ |
   | พยากรณ์อากาศ | 7 วัน, ฝนรายชั่วโมง 48 ชม., โอกาสเกิดฝน |
   | พยากรณ์น้ำท่า | ปริมาณน้ำท่า 14 วัน, วันที่คาดว่าสูงสุด, แนวโน้ม, ระดับเขื่อนใน 7 วัน |
   | ภาพรวมรายจังหวัด | จัดอันดับความเสี่ยงทุกจังหวัด คลิกแถวเพื่อเลือกจังหวัด |
   | แผนรับมือ | เช็กลิสต์ก่อน/ระหว่าง/หลังน้ำท่วม และเบอร์ติดต่อฉุกเฉิน |
5. ข้อมูลรีเฟรชอัตโนมัติทุก 15 นาที หรือกดปุ่ม **⟳ รีเฟรช**

## API

| Endpoint | คำอธิบาย |
|---|---|
| `GET /api/geo` | รายชื่อภาคและจังหวัด |
| `GET /api/districts?province=<รหัส>` | รายชื่ออำเภอของจังหวัด |
| `GET /api/area?region=&province=&amphoe=` | เขื่อน สถานีวัดน้ำ พยากรณ์ ความเสี่ยง ของพื้นที่ที่เลือก |
| `GET /api/overview?region=` | สรุปรายจังหวัด |

`province` ใช้รหัสจังหวัด 2 หลัก (เช่น `40` = ขอนแก่น)

## แหล่งข้อมูล

- เขื่อน: กรมชลประทาน (app.rid.go.th) — เฉพาะเขื่อน 35 แห่งที่ API เปิดให้
- ระดับน้ำแม่น้ำ: สสน. ThaiWater (api-v3.thaiwater.net)
- พยากรณ์อากาศและน้ำท่า: Open-Meteo (Forecast API และ Flood API/GloFAS)
- รายชื่ออำเภอ: github.com/kongvut/thai-province-data

## ข้อควรระวัง

- เกณฑ์ประเมินความเสี่ยงเป็นเกณฑ์ที่กำหนดเองเพื่อช่วยคัดกรองเบื้องต้น ไม่ใช่ประกาศทางการ
- พยากรณ์น้ำท่ามาจากแบบจำลองกริด ~5 กม. ไม่ใช่ค่าที่สถานีวัดจริง
- ควรยึดประกาศของกรมอุตุนิยมวิทยา กรมชลประทาน และ ปภ. (โทร 1784) เป็นหลัก
- หากต้นทางล่ม ระบบจะแสดงข้อมูลเก่าที่แคชไว้ (ถ้ามี) หรือแจ้งข้อผิดพลาดบนหน้าเว็บ
- เซิร์ฟเวอร์ที่รันด้วย `python app.py` เป็น development server หากนำขึ้นใช้งานจริงให้รันด้วย `gunicorn`/`waitress` แทน
